01 TOKENISATION

Text becomes a list of integers.

A token is the model’s basic unit of text. A tokeniser breaks the prompt into pieces, maps each piece to an integer ID, and passes that sequence forward. Pieces are often smaller than words.

The key idea: models calculate with token IDs, not characters.

Common words may be one token; rare words may split into several. Spaces and punctuation can belong to tokens too, which is why token counts do not equal word counts.

02 EMBEDDINGS

Each token ID becomes a learned vector.

The embedding layer gives every token a long list of numbers. Training moves related tokens toward useful regions in this high-dimensional space. Position information is added, so word order is not lost.

The key idea: geometry carries learned associations.

An embedding is not a dictionary definition. It is a parameter vector shaped by many prediction tasks. Contextual models then keep changing each token’s representation through later layers, so one word can mean different things in different sentences.

03 SELF-ATTENTION

Tokens gather context from other tokens.

Attention compares each token with earlier tokens. The model produces a query, key, and value for every position; their interactions determine how much information each token takes from the others.

The key idea: attention is a weighted exchange of information.

For one attention head, query-key similarity becomes a set of weights. Values are mixed using those weights. Multiple heads can track different relationships, such as subject–verb links, nearby phrases, or repeated names.

04 FEED-FORWARD BLOCK

A private transformation at every position.

After attention mixes information across tokens, the feed-forward network processes each token vector independently. It expands the vector, applies a nonlinearity, then projects it back to the model width.

The key idea: attention exchanges, the feed-forward block transforms.

You can think of the expanded layer as a bank of learned detectors. They respond to combinations of features, and the return projection writes useful signals back into the token’s shared representation.

05 TRAINING OBJECTIVE

Learning means predicting the next token.

A decoder-only language model is trained on many sequences to assign high probability to the token that actually appears next. Cross-entropy loss penalises confident mistakes; gradients adjust the weights.

The key idea: one objective repeated at every position.

Each prefix supplies a prediction target. During training the loss is computed from the model’s entire next-token distribution, not only from the top guess. Better predictions lower the loss.

06 TOKEN SAMPLING

The next token is a choice, not a secret answer.

The model outputs a score for every vocabulary item. Softmax turns those scores into probabilities. A decoding rule chooses one token, appends it to the context, and starts the next forward pass.

The key idea: temperature reshapes the distribution before random sampling.

Greedy

Always take the highest-probability token.

Temperature

Lower values sharpen the distribution; higher values flatten it.

Top-k / top-p

Restrict the draw to a shortlist or a cumulative probability mass.

THE COMPLETE LOOP

Predict one token. Append it. Predict again.

context→ model→ probabilities→ sample→ append + repeat

A convincing answer is assembled one token at a time. The architecture supplies useful probability estimates, but it does not contain a separate database lookup that hands over the full reply.
